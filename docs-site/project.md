# Contributing and project policies

InsightDock Charts is an OSS C++17 library for report generation and embedded devices. Contributions
are reviewed through GitHub issues and pull requests. The next priorities are reliable output
and installation, common 2D plotting workflows, and statistical chart coverage.

- [Roadmap](https://github.com/aavazir/insightdock-charts/blob/main/ROADMAP.md): implemented features,
  current milestones, completion criteria and future workstreams.
- [Contributing](https://github.com/aavazir/insightdock-charts/blob/main/CONTRIBUTING.md): building,
  formatting, meaningful regression tests and public API documentation.
- [Governance](https://github.com/aavazir/insightdock-charts/blob/main/GOVERNANCE.md): maintainer
  responsibilities, API decisions, review and dependency updates.
- [Security policy](https://github.com/aavazir/insightdock-charts/blob/main/SECURITY.md): supported
  versions, private vulnerability reports, resource bounds and trusted-font requirements.
- [Release process](https://github.com/aavazir/insightdock-charts/blob/main/docs/RELEASE.md): release
  checks, compatibility policy and publication requirements.
- [Code of conduct](https://github.com/aavazir/insightdock-charts/blob/main/CODE_OF_CONDUCT.md)
  and [support](https://github.com/aavazir/insightdock-charts/blob/main/SUPPORT.md).

Source compatibility and binary compatibility are separate promises. Rebuild applications when
upgrading between minor versions. See [Thread safety and ABI](guides/thread-safety-and-abi.md)
for the details.
