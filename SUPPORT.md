# Getting help

- **Questions and ideas:** use [GitHub Discussions](https://github.com/aavazir/insightdock-charts/discussions).
- **Bugs:** open an [issue](https://github.com/aavazir/insightdock-charts/issues/new/choose) with a minimal reproduction.
- **Security problems:** report privately as described in [SECURITY.md](SECURITY.md); do not open a public issue.
- **Documentation:** https://aavazir.github.io/insightdock-charts/ (the [troubleshooting guide](https://aavazir.github.io/insightdock-charts/guides/troubleshooting/) covers build and ABI problems).
